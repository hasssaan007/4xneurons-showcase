# 4xNeurons

> **Showcase page.** This repository is a public showcase of a **private repository**:
> it contains a description of the work only, with **no source code**.

A **trading-technology web platform**: marketing site, product demos and a client-side sync bridge that pulls a trader's MetaTrader 5 account data into the web app.

## What I built

- **Web application** (React, Vite, TypeScript, Tailwind) with the public site and product pages
- **MT5 client sync** - a client-side bridge that reads a trader's MetaTrader 5 account and syncs it to the platform, with a VPS deployment path for always-on operation
- **Interactive product demo** embedded in the site
- **Supabase backend** for auth and data
- **Search strategy** - structured work on search and AI-answer visibility, including sitemap and indexing workflow

## Stack

React, Vite, TypeScript, Tailwind CSS, Supabase, MetaTrader 5 (MQL5 bridge), VPS deployment
